De las hojas sueltas a un solo registro

Cuando el inventario vive en libretas y hojas de cálculo distintas, nadie sabe con certeza qué hay en cada lugar.

Sin sistema

  • Cada sucursal lleva sus propias cuentas.
  • El faltante se descubre cuando el cliente ya lo pidió.
  • Los traspasos se acuerdan por llamada o mensaje.
  • Nadie sabe quién movió la mercancía.

Con MedInventory

  • Una sola consulta muestra matriz y sucursales.
  • El sistema alerta cuando el stock llega al mínimo.
  • Cada traspaso queda registrado con fecha y responsable.
  • Los permisos limitan quién puede modificar qué.

Cómo se mueve un producto

El recorrido de una solicitud de reabastecimiento, de principio a fin.

  1. Se detecta el faltante

    El sistema marca el producto cuando baja del mínimo definido.

  2. La sucursal solicita

    El encargado pide la cantidad necesaria a la matriz.

  3. La matriz confirma

    Se revisa la existencia y se autoriza el envío.

  4. Se actualiza todo

    Las existencias de ambas ubicaciones cambian y el movimiento queda en el historial.

Preguntas frecuentes

Lo que suelen preguntar antes de empezar.

¿Cuántas sucursales puedo manejar?

El proyecto está pensado para una matriz y varias sucursales, y puede ampliarse agregando nuevas ubicaciones.

¿Puedo definir un mínimo distinto por producto?

Sí. Cada producto tiene su propio nivel mínimo, y la alerta se activa al llegar a él.

¿Se puede saber quién hizo un movimiento?

Cada entrada, salida o traspaso se guarda con fecha, usuario y cantidad.

¿Funciona desde el celular?

La interfaz es adaptable, así que puede consultarse desde computadora, tableta o teléfono.
