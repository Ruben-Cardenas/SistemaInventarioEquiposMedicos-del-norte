# Sistema de Inventario de Equipos Médicos

## Descripción
Sistema web diseñado para administrar y controlar el inventario de productos y equipos médicos de una empresa con una matriz y diferentes sucursales.

## Problema
El control manual de productos dificulta conocer las existencias, registrar movimientos y controlar los artículos enviados a cada sucursal.

## Objetivo
Facilitar la administración del inventario mediante un sistema que permita registrar productos, consultar existencias y controlar los movimientos entre sucursales.

## Funcionalidades principales
- Registro y administración de productos.
- Control de existencias.
- Organización por categorías.
- Registro de movimientos de inventario.
- Administración de sucursales.
- Consulta de reportes.

## Tecnologías
- HTML
- CSS
- Git
- GitHub

## Proyecto académico
Desarrollo de un sistema de inventario para una empresa de equipos médicos.
